# ВТБ Онлайн · Защита переводов

Неофициальный учебный прототип команды студентов для ВТБ. Новый блок «Защита переводов» показан внутри «Защиты близких». В одном проекте связаны приложение Галины Петровны, приложение её дочери Анны и демонстрация разговора с банком.

[Открыть прототип на GitHub Pages](https://unteku3.github.io/vtb-transfer-protection/).

## Запуск

Распакуйте проект целиком и откройте `index.html`. Установка и сборка не нужны; стили, JavaScript и шрифты находятся рядом с HTML. Альтернатива: `python3 -m http.server 8000` в папке проекта, затем `http://localhost:8000`.

`model.js` содержит правила и расчёт резервов, `screens.js` — экраны нового блока, `app.js` — навигацию и управление, `icons.js` — иконки, `fonts/` — шрифты и лицензию.

## Как показать

Подробный маршрут на шесть минут — в [инструкции](Как-показать-прототип.txt). Начните с «Безопасность» → «Защита близких» → «Защита переводов: выключена», включите защиту, затем отправьте демонстрационные 300 000 ₽ Сергею. Откройте квитанцию, переключитесь на Анну и заморозьте перевод. Вернитесь к Галине и покажите обращение в банк.

Переключатели ролей над телефоном сохраняют общий перевод. Выбор отдельного сценария справа сбрасывает текущий показ и запускает подготовленное состояние с включённой защитой. В узком окне используйте «Экран» и «Сценарии». «Начать демонстрацию заново» возвращает начальное состояние; перезагрузка страницы также начинает новую демонстрацию.

Кнопки «+24 часа» и «+48 часов» управляют временем модели. Замороженный перевод остаётся в резерве после истечения срока. Отдельно доступны повторный перевод на 20 000 ₽, первая отправка 50 000 ₽, прежний получатель, свои счета и покупки картой/QR. Кнопок самостоятельной отмены и размораживания в телефоне нет. Результат разговора с сотрудником выбирает ведущий во внешней панели после перехода к звонку или чату.

## Границы модели

Это локальная симуляция: настоящих переводов, уведомлений, звонков и сообщений в банк нет. Суммы и реквизиты демонстрационные; ввод в чат остаётся в памяти вкладки. «Поделиться» скачивает локальную HTML-квитанцию с пометкой «Учебный прототип», а не отправляет её другому человеку. Состояния, баланс и резерв пересчитываются моделью, а не подменяются независимыми картинками.

Точка входа и согласованные тексты сохранены по заданию команды. Существующее подтверждение операций защитником не моделируется: порядок его совместной работы с новым ожиданием на 24 часа в задании не определён. Правила 24/48 часов описывают предложенный блок, а не текущие условия банка. Для сравнения: [официальная страница «Защиты близких»](https://www.vtb.ru/personal/online-servisy/zashchita-blizkikh/).

Дизайн использует публичные ориентиры ВТБ Онлайн; точное соответствие внутреннему UI kit не заявляется. Встроен **PT Root UI** от Paratype по **SIL Open Font License 1.1** как замена Omega UI. [Лицензия](fonts/OFL.txt), [происхождение файлов](fonts/PROVENANCE.json). Эта лицензия относится к шрифту, а не автоматически ко всему проекту.

## Проверки и публикация

`npm test` запускает 64 проверки модели, экранов и навигации; зависимости устанавливать не нужно. GitHub Pages публикует корень ветки `main`, обновляясь после отправки изменений.
